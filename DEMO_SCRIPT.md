# Demo Video Script (about 2–3 minutes)

**Before recording:** Run `python app.py`, open `http://127.0.0.1:5000`, and prepare a sample resume that contains no sensitive personal information.

**Opening (15 seconds)**  
“Hello, my name is [Name]. This is my Smart Resume Analyzer with AI-Based Feedback capstone. It demonstrates resume text extraction, role-specific keyword matching, rule-based scoring, and improvement suggestions.”

**Upload and role selection (20 seconds)**  
“On the home page, the user uploads a PDF or DOCX resume and chooses a target role. I will select AI Engineer and submit the form.”

**Results (45 seconds)**  
“The dashboard displays a heuristic readiness score and the number of words extracted. The section checklist shows whether common sections were detected. The keyword panel lists terms found in the resume and terms not detected for the selected role.”

**Feedback (30 seconds)**  
“The feedback list provides suggestions based on missing sections and keywords. These are suggestions only. Users should add skills and experience only when they are accurate.”

**Role comparison (20 seconds)**  
“I can select another role, such as Data Analyst, to demonstrate that the keyword checklist changes according to the chosen role.”

**Limitations (15 seconds)**  
“This is an educational prototype. Keyword matching is literal, the score is heuristic, and it is not an official ATS result. Scanned PDFs are not supported unless they contain extractable text.”

**Closing (10 seconds)**  
“This project demonstrates file handling, text processing, rule-based analysis, and web application integration. Thank you.”

Replace placeholders and record only after verifying the app works.
